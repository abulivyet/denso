# 南沙电装 OMS 系统 — 操作手册

**系统名称：** 南沙电装 OMS  
**适用对象：** 现场操作员、仓库打印人员、系统管理员  
**配套：** 开发细节见《南沙电装OMS-开发文档》  
**说明：** 左侧菜单名称以本账号权限为准。若某功能没有入口，请管理员在「角色菜单」中勾选。

---

## 1. 登录、界面、退出

### 1.1 登录

1. 用浏览器打开系统地址（由现场提供，建议收藏）。  
2. 页面标题为「南沙电装OMS系统」，输入**账号**、**密码**。  
3. 可选「记住登录」（仅本机浏览器）。  
4. 点「立即登录」。成功进入主界面；失败会提示「无效的账号或密码」。  

账号由管理员在「用户」里开通，默认密码以管理员告知为准，首次登录后建议改密。

登录状态大约 **1 小时** 有效。超时后点查询会提示请先登录，将跳回登录页，重新登录即可。未保存的填写内容会丢失，长时间操作请及时点保存/下载。

### 1.2 主界面

- **顶部：** Logo、系统名、当前用户、退出登录。  
- **左侧：** 折叠菜单。点有链接的菜单项，中间打开对应功能页（可同时开多个标签）。  
- **底部：** 版权信息。  

点右上角「退出登录」→ 确定，清除登录信息并回登录页。

### 1.3 列表页通用操作

多数业务页结构相同：

1. **上方查询区**（可折叠）：填条件 →「查询」；「重置」清空条件。  
2. **表格：** 可勾选多行；部分列头有漏斗可再筛选。  
3. **底部分页：** 翻页、改每页条数。  
4. **工具栏按钮：** 上传、下载、删除、重新解析等，一般先勾选行再点按钮。

查询后请看「解析状态」：只有**成功**的记录才适合下载打印。

## 2. 使用前：原单位表（量表）

标签上的**电装品番、客户品番、收容数、每托箱数、车型、品名**来自原单位表。量表未导或品番不一致，确认表/看板会缺数或解析失败。

**建议：** 客户更新零件清单后，先导量表，再导订单文件。

### 2.1 导入

打开「原单位」相关菜单。

| 按钮 | 用途 | 覆盖范围 |
|------|------|----------|
| 丰田导入 | 长春、一汽发动机 | 会先删原有 FTEC/FTET 再写入新表 |
| 本田导入 | 东风、佛山、广州本田 | 会先删原有 DHEC/CHAM/GHAC 再写入 |

步骤：点对应导入 → 选择 Excel → 上传。请确认文件是最新、正确的模板，**导错会清空该侧旧数据**。

### 2.2 导出

「丰田导出 / 本田导出」下载当前库里的量表，用于核对或备份。导出文件名类似 `toyota原单位表.xlsx` / `honda原单位表.xlsx`。

### 2.3 查询

可按客户简称、品番、车型等查询。导入后抽查几条收容数、托标箱数是否正确。

## 3. 上传文件的共同规则

### 3.1 怎么传

1. 点「上传文件」，弹出「导入文件」窗口。  
2. 点击灰色区域选文件，或把文件拖进去。可一次多个。  
3. 列表显示文件名、大小。点窗口内「上传文件」。  
4. 系统先检查是否上传过（按文件内容，不是只看文件名）。重复会提示「文件 xxx 已上传过」。  
5. 通过后开始上传。大文件请等待，不要关页。成功提示「文件上传完成」，列表会刷新。

### 3.2 系统靠文件名和内容识别客户

**不要改客户原始文件名。** 改名可能导致分到错误客户或无法识别。

允许的类型：`.rar` `.zip` `.xls` `.xlsx` `.pdf`。

识别对照见第 4～8 节各客户。PDF 还会打开看正文关键字（如「送货传票」「零件明示卡」），与文件名一起判断。

无法识别的 PDF 会提示「不能识别的 PDF 类型」，请核对该文件是否为本系统支持的版式。

### 3.3 解析状态

| 显示 | 含义 | 操作建议 |
|------|------|----------|
| 解析中 | 后台正在拆文件、转 PDF | 等待，过一会点查询刷新 |
| 成功 | 已生成可下载文件 | 可下载、填确认表备注 |
| 失败 | 出错 | 看「解析结果」列；可重新解析 |
| 重新解析 | 正在按原文件再生成 | 等待完成 |

压缩包较大时可能数分钟。超过很久仍「解析中」，可勾选后点「重新解析」；仍不行把**文件名 + 解析结果全文**发给维护人员。

部分文件（周订单、取货计划、直链配货、广本 PDF 拆分）上传过程中就处理完，状态会直接为成功，不必等解析。

### 3.4 重新解析 / 删除

- **重新解析：** 勾选一行或多行 →「重新解析」→ 确定。会删除该单已生成的明细后再拆一遍。原上传文件还在服务器上。  
- **删除数据：** 勾选 →「删除数据」。导入记录和解析明细一起删，**不可恢复**。若文件还要再处理，删完需重新上传。

## 4. 长春（FTCE）与一汽发动机（FTET）

**入口：** 订单导入（客户下拉只有「长春」「一汽发动机」）。

### 4.1 应准备的文件

| 客户 | 文件 | 文件名要求 | 说明 |
|------|------|------------|------|
| 长春量产 | rar 压缩包 | 保持客户原名，常含日期 | 内含捆包 List、货垛标签、看板、受领书等 |
| 长春补给 | Excel | 必须含 **FTMS** | 补给订单 |
| 一汽量产 | zip | 一般不含 BJ | 量产看板/受领书等 |
| 一汽补给 | zip | 文件名含 **BJ** | 补给 |
| 一汽直连 | Excel | 含 **直链配货** | 链标签数据，不拆 PDF |
| 一汽集货 | Excel | 含 **集货计划** | 写入集货计划，不拆 PDF |

一汽 zip 里若文件名含 **TB**，会按链数据生成直连标签。链没导时，解析结果会提示「未找到链数据，请上传」。请先在本页上传直链配货 Excel，再到「链」菜单按订单号、背番核对 l1～l14。

### 4.2 查询条件

客户、订单号、订单便次、传票作成者、解析状态、导入时间从/至、发货日期从/至、下载次数。

列表主要列：导入时间、解析状态、解析结果、客户、客户代码、订单号、类型（量产/补给等）、便次、发货日期、作成者、文件名称、解析起止与时长、计划到货日期、下载次数、确认表备注。

### 4.3 行内快捷下载（图标）

| 图标列 | 作用 |
|--------|------|
| 受领书 | 直接下该单受领书 |
| 托标签 | 码垛/托标签 |
| 箱标签 | 弹出「小纸张」或「A4 穿透」再下载 |
| 确认单 | 确认表 |
| 确认表备注-填写 | 打开备注窗口，确定后保存 |

### 4.4 批量「标签下载」

勾选**已成功**的行 →「标签下载」→ 勾选类型 → 确定。得到 zip 或（仅套票时）PDF。

| 选项 | 说明 |
|------|------|
| 确认表 | 出货核对用 |
| 箱标签 | 须再选 **小纸打印** 或 **A4 穿透打印** |
| 托标签 | 码垛单 |
| 合并成一个文件 | 与托标签一起勾：多张码垛合成一个 PDF（选了 A4 穿透后该项无效） |
| 纳品书 | 受领书 |
| 取套票 | 按固定顺序合成一套；一汽会附带**核对记录表** |

打印建议：箱标签按现场打印机选小纸或 A4；套票用于装订成套。下载次数会加 1，可在列表里看到。

### 4.5 推荐顺序

1. 更新丰田原单位表。  
2. 一汽若要链标签：先上传直链配货 Excel，在链页面核对。  
3. 上传 rar/zip/FTMS。  
4. 等成功 → 填确认表备注（如需要）→ 下载套票或分项标签 → 打印。

## 5. 佛山本田（CHAM）

本田三家的**原始文件**都在「本田订单导入」页上传（客户可筛佛山/东风/广州）。佛山另有周订单页、出货页。

### 5.1 周订单

**文件：** Excel，文件名必须包含 **销售订单工作台整单导出**。

上传后写入周订单，出货指示会按物料、计划代码、需求日去匹配传票号。

周订单页可按条件查询，可删除错误导入的行。列包括：订单状态、订单号、发布日期、客户名称、传票、物料编码/名称、计划代码、需求日期、收货时间、数量、单位、订单类型、收货地址、搬入场所、新收荷日期等。

### 5.2 出货类 PDF（务必按顺序）

**推荐顺序：**

1. 周订单 Excel  
2. 传票 PDF、看板 PDF、托标签 PDF（可分多次）  
3. 最后：**出货指示单 / 送货单** PDF  

系统打开 PDF 看文字判断类型（无需改文件名，但不要把几种单子打成无法识别的扫描件）。

| 系统识别 | 类型 | 做什么 |
|----------|------|--------|
| 送货传票 + CHAM | 传票 | 拆成单张，按传票号存放 |
| 部品明示卡 | 看板 | 按传票号归文件夹 |
| 托标签-CHAM | 托标签 | 拆分后按出货号保存 |
| 出货指示单 | 送货单 | 按页匹配周订单，拼确认表和已拆单据 |

指示单对不上周订单行时，该单会标「是否有补给品 = 是」。

### 5.3 佛山出货页操作

查询：导入时间、客户、类型、解析状态等（与导入列表类似）。

工具栏：上传文件、标签下载、重新解析。

**标签下载**勾选：

- 确认表  
- 传票  
- 托标签  
- 箱标签（看板）  
- 取货指示单  
- 取套票  

行内也可分别点传票 / 托标签 / 箱标签 / 指示单下载。下载前确认解析状态为成功。

## 6. 东风本田（DHEC）

### 6.1 上传（本田导入页）

| 文件 | 文件名要含 | 结果 |
|------|------------|------|
| 量产周订单 Excel | `DHEC` 或 `GHEC`，且含 **order** | 写入周订单，一般立即成功 |
| 取货计划 Excel | `DHEC`/`GHEC` 且含 **PLAN** | 写入日计划 |
| 看板 PDF | 正文有「零件明示卡」 | 拆到看板目录，按传票号命名 |
| 传票 PDF | 「送货传票」+ DHEC | 拆到传票目录 |

日计划下载时按**传票号找文件夹里的 PDF**，不按导入记录关联。因此看板/传票必须先传，且拆出的文件名要能对上计划里的传票号。

### 6.2 周订单页

查询零件号、传票、收货日期等，可删除错行。与广本周订单列类似（供应商、收货地点、零件、计划代码、订货数量、传票号码、版本、周次等）。

### 6.3 日计划 — 成套下载

**入口：** 东风日计划。

1. 查询计划离开日期、车组、传票号等。  
2. **只勾选同一个取货车组**的行。车组不一致会提示无法下载。  
3. 点「标签下载」，勾选：  
   - **确认表**  
   - **箱标签**  
   - **取套票**  
4. 确定后下载。确认表备注可在行内「填写」。

SP 类计划会单独生成 SP 标签（用系统内 DHEC 模板），并单独合并传票。普通量产看板按零件号、落点、计划时间排序后合并。

若提示找不到文件：对应看板/传票 PDF 未上传，或传票号与 PDF 文件名不一致，请补传后重试。

## 7. 广州本田（GHAC）

### 7.1 上传（本田导入页）

**Excel**

| 文件名 | 系统当作 |
|--------|----------|
| 含 **GHAC** | 周订单（内部再判断是否八千代/阶段品计划） |
| 含 **取货计划** 或 **SP计划** | 取货计划（含八千代、阶段品、SP） |

**PDF（按内容，也可看文件名 LABEL_D / LABEL_T）**

| 识别 | 类型 | 存放（系统内） |
|------|------|----------------|
| 送货传票 + GHAC | 传票 | SUMMONS，文件名与品番+版本对应 |
| 取货指示书 | 取货指示书 | INSTRUCTIONS，按指示号 |
| 传票更改清单，或传票+指示书合订 | 01 版 | 一次拆出传票和指示书 |
| LABEL_D 或 PLS 版式 | 箱标签/看板 | PLS |
| LABEL_T | 托盘标签 | PALLET |
| 发行顺序号 | 追溯标签 | TRACE |

广本 PDF 上传时就会拆完，状态多为直接成功。

### 7.2 周订单页

查询、下载、删除。列与东风周订单类似。

### 7.3 取货计划 — 按指示号出成套文件

**入口：** 广本取货计划。

列表：上传日期、取货日期/时间、**取货指示号**、版本、取货车次、线路、供应商、广本工厂、计划代码、下载次数、确认表备注等。

步骤：

1. 先把本指示号需要的传票、指示书、PLS、托盘、追溯都上传成功。  
2. 勾选该指示号下的计划行。  
3. 「标签下载」，勾选需要的：  
   - 确认表  
   - 取货指示书  
   - 传票  
   - 托盘标签  
   - 箱标签  
   - 追溯标签  
   - 取套票  
4. 系统按指示号到文件夹里**按文件名匹配**后合并下载。缺哪种 PDF，成套里就缺哪一类，解析结果/日志会写「未找到对应传票」等。

**八千代 / SP / 阶段品：** 指示号或计划名称带这些字时，走单独套票和看板模板，与量产拼版不同。确认表客户名会显示为八千代等。

**追溯标签：** 按零件号 + 收货日期时间 + 收货地点匹配。用过的标签会记下，避免下次重复打同一张。不要手工删除服务器上 TRACE 目录里的 `_state_` 文件。

确认表备注同样在行内填写。

## 8. 确认表备注

下列页面行内有「确认表备注 → 填写」：

- 长春/一汽订单导入  
- 佛山出货  
- 东风日计划  
- 广本取货计划  

操作：点填写 → 编辑文本 → 确定。系统会写入确认表 Excel 并再转 PDF。  

同一客户可存一份**批量默认备注**（一汽还会按订单号前两位区分），下次打开填写框可能自动带出，改完确定即可。

请在**下载套票之前**填好备注，避免打完再改又下一遍。

## 10. 系统管理（管理员）

### 10.1 用户

## 12. 打印与下载注意

1. 先看解析状态 = 成功，再下载。  
2. 套票、A4 合并可能较慢，等浏览器开始下载再关提示框。  
3. 下载次数仅作参考，不限制次数。  
4. 打印前抽查首页：客户名、订单号、日期、品番、数量。  
5. 箱标签选小纸还是 A4，与现场打印机、纸张一致。  
6. 同一指示号/车组不要混勾其它单号的行。

## 13. 常见问题

**提示文件已上传过**  
相同内容已导入。要再处理：对原记录重新解析，或先删除原记录再传。

**不能识别的 PDF 类型**  
不是系统支持的版式（缺关键字，或纯图片扫描）。用客户原始电子 PDF，不要先打成图再扫描。

**解析失败：未找到文件**  
服务器上原文件被挪走或磁盘路径变化。联系维护，不要只在本机重传同名文件（可能因 MD5 被拦）。

**解析失败：模板未找到**  
服务器模板缺失或路径配置不对。维护人员检查 `UploadFiles` 下确认表、货垛、外箱单等模板。

**未找到链数据**  
一汽 TB 包需要链。先上传直链配货 Excel，链页面能查到该订单后再重新解析 zip。

**通过品番/背番未在量表获取到数据**  
原单位表没有该零件。补量表（丰田或本田导入）后重新解析。

**东风：取车组不一致**  
只勾同一取货车组。

**东风/广本成套缺页**  
对应 PDF 没传，或品番、版本、传票号与计划不一致。在本田导入列表确认该 PDF 为成功，文件名未改。

**佛山指示单对不上**  
周订单或传票/看板未齐，或传票号不一致。按 5.2 节顺序补传后，对指示单重新解析。

**广本追溯打重复或打不到**  
匹配条件是零件+时间+地点；已用记录在服务器。不要清 TRACE 状态文件；换计划日期应使用对应批次的追溯 PDF。

**一直解析中**  
刷新查询。仍不变则重新解析。再不行提供文件名、导入时间给维护查 `ChyLog`。

**提示请先登录**  
登录过期，重新登录后再操作。

**下载提示未找到解析后的数据，请重新解析**  
该行还没有明细（失败或未解析完）。等成功或重新解析。

## 14. 现场应急（操作员可做的）

| 情况 | 可自行尝试 | 需维护 |
|------|------------|--------|
| 单笔失败 | 重新解析一次 | 仍失败则给文件和报错原文 |
| 传错文件 | 删除该导入记录，传正确文件 | — |
| 量表过期 | 重新导入对应丰田/本田量表 | 导入后旧客户数据被覆盖，需确认文件正确 |
| 打错套票 | 改备注或重新下载，不必重新上传 | — |
| 全员进不去 | — | 查 IIS、数据库是否启动 |
| 所有 Excel 转 PDF 失败 | — | LibreOffice / 授权 / 磁盘空间 |

日常不要删除服务器 `Uploads`、`UploadFiles` 目录中的历史文件，否则已成功的记录也无法再下载，只能重新上传解析。

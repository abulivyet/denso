## 现场处理优先级（当时紧急单）

1. **东本 5/22 套票仍是 5/19：** 先删日计划里 5/19 旧行再下载（问题 3）。  
2. **CHAM 取消订单：** 周订单页删除后再对应出货（问题 4）。  
3. **广本 SP 下不下来：** 先看报错传票号是否已上传（问题 2）。  
4. 其余为套票内容不准（合并、少托标、数量、版本），按上表现场规避，程序侧列入缺陷修改。

## 2026年3月现场问题（当时已处理，补记）

现场按客户单据做了应急处理（补传、删旧计划、补导周订单、重新解析、手工核打），程序侧根因大多仍在，后续改代码时按本表。

3 月这批主要集中在四类：

1. **广本看板/套票抓取范围不对：** 同订单分托、分车次时看板不按托号排，甚至把整单看板打进两个车次；八千代删旧导新仍带旧品番，或把当天所有出货打进一份套票。  
2. **确认表与指示单不一致：** 广本尾数托箱数不显示；佛山确认表出货日比指示单晚一天，重新解析后日期变成解析当天、订单号重复。  
3. **「解析成功」不等于套票齐：** 东风缺 13 周周订单时套票缺页仍显示成功；长春补给缺托标签/现调品纳受领书。  
4. **八千代指示号生成规则：** 同一天有的相同、有的不同，一二厂托号会连续或各自从 1 起导致重复。

## 建议纳入常规的程序改造（汇总）

| 模块 | 改造点 |
|------|--------|
| GHAC 套票 | 输出文件名含供应商；SP/八千代查询加供应商过滤 |
| GHAC SP | 去掉写死版本 `00`；下载用计划实际版本；异常信息写清缺的是传票还是看板 |
| GHAC 托标签 | 拆分同托多页文件名加序号，禁止覆盖 |
| GHAC 确认表 | 汇总前按品番去重；忽略填色空行；满托+尾箱都要显示 |
| GHAC 指示书 | 同指示号多版本只取最新 |
| GHAC 看板 | 按托号排序；分纳按车次+托号匹配，禁止退回整单品番；合并去重 |
| GHAC 八千代 | 指示号按日出货日+厂别稳定生成；重导按旧指示号整单删除；下载不得带出当天其它计划 |
| DHEC 日计划 | 导入时按车组清理不在新文件中的旧行；下载带出货日期条件；缺周订单时不得显示解析成功 |
| CHAM 周订单 | 作废状态，匹配排除作废 |
| CHAM 确认表 | 出货日取指示单，不用服务器当天；重解析不得重复配订单号 |
| FTEC 确认表 | 转 PDF 前强制一页 |
| FTEC 补给 | 缺托标签/现调品纳受领书时解析失败并写明缺项 |
